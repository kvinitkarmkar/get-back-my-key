## [1.0.0] - 2026-10-20

### Added
- Add and track password attempts with `pending`, `failed` and `success` statuses
- Duplicate combination detection
- Search and status filters
- Live stats (total, tried, successful)
- Copy to clipboard
- Delete with confirmation
- Success confirmation with celebration screen, particles and sound
- Export and import JSON backup
- Persistent storage with `localStorage`
- Keyboard shortcuts (`Enter`, `Esc`)
- Responsive layout and reduced-motion support

### Changed
- Project split into modular files (`css/` and `js/`)
